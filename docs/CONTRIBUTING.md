# Contribution Workflow

## Before changing code

- Read the relevant documentation.
- Keep the change focused on one milestone.
- Confirm whether the behavior needs a test or documentation update.

## Commit style

Use short, descriptive messages, for example:

```text
feat: add video frame inference
test: cover empty upload validation
docs: explain CPU benchmark setup
```

## Pull request checklist

- The project still starts from a clean setup.
- Tests pass.
- New behavior is documented.
- No credentials or private media are included.
- Performance claims include the hardware and settings used.
