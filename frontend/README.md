# EdgeTrack Dashboard

The React dashboard will be initialized in Milestone 2.

The intended dashboard workflow is:

1. Choose a sample video or upload a short video.
2. Start processing.
3. View annotated frames with object labels and track IDs.
4. Inspect counts, confidence, FPS, latency, and resolution.
5. Pause, reset, or change the confidence threshold.

Until then, the FastAPI service in `backend/` is the active implementation surface.
